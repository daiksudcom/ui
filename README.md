# @daiksudcom/ui

`@daiksudcom/ui` は、Home と Blog が利用する Astro コンポーネント、CSS、デザイントークンの公開契約を定義するリポジトリです。

## 現在の状態

実装開始前の基準として、観測可能な振る舞いを Gherkin、技術的な決定を Architecture Decision Records（ADR）で確定しています。
